## Fix hints

- **non-library-control** — use the library component (components.md › Component Inventory): .btn + variant + size, .chip, .checkbox, .radio, .switch, .search-input, .input / .e-permits-fo-input; a genuinely new control is first documented in components.md (inventory row + section) — ask the PO before inventing one
- **field-height-phone** — phones (≤760) use the library default field size = 48 (`.input` / `.search-input` default, FO fields via the ≤720 FO block that sets 48 + 16/24); never a fixed 40
- **field-height-desktop** — desktop uses the library medium size = 40 (`.input--medium`, `.search-input.medium`, FO fields 40)
- **field-text-phone** — phone field text = 16/24 (`--font-size-fs-16` / `--line-height-lh-24`; below 16 iOS zooms the page)
- **field-icon-size** — icons inside a field follow the library size for the field: 48 → 24 (`--icon-size-default`), 40 → 20 (`--icon-size-medium`), 32 → 16 (`--icon-size-small`)
- **look-alike** — styled like a control but not one: make it the library component (button.btn, a.link, .chip) or drop the control look
