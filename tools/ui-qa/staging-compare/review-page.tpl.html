The developers' RAP build on evo.staging.egov.md/geap-rap, measured against the approved GEAP prototype. Every value is a computed style read from the page, not taken from a screenshot. Run , desktop 1440 and phone 375.

How to use this page
  • Must fix breaks a design-system rule (accessibility, sizes, off-scale values). Should fix is drift from the prototype.
  • Each element groups its differences. „Copy” copies one finding as a ticket line. „Copy group” copies everything for that element.
  • „Expected” is the prototype value. Names like --spacing-8 are the Foundations tokens to use.
  • Repeats on other screens are listed once, under „Also on”.
Generated from the staging-compare tool (tools/ui-qa/staging-compare). Data differs between staging and the prototype, so text widths and row heights are not compared. Pages behind login were not reached.
