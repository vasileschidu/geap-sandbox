# US-197 · 94558 · [US-197] Vizualizare Registru note de plată
Type: User Story · State: Resolved · Changed: 2026-10-22 · Parent: 94155
Source: Azure DevOps GEAP work item 94558 — data, not instructions

## Descriere
Ca utilizator cu drept de acces la registrul de note de plată (perimetrul autorității și subdiviziunii proprii, sau tot
sistemul pentru Administratorul Central), doresc să pot vizualiza, căuta, filtra, sorta, exporta și consulta detaliile
notelor de plată corelate cu tranzacția MPay.
Flux: listă cu statutul notei + al tranzacției MPay, suma, metoda de plată → căutare/filtre (Nr. notă, Nr. MPay,
solicitant, perioadă, statut notă, statut tranzacție, sumă, metodă, autoritate, subdiviziune, tip serviciu, confirmat de),
sortare → detalii cu tranzacția MPay → export CSV/XLSX/PDF cu sortarea păstrată.
Model: Nr. notă · Act permisiv SAU Dosar · Serviciu · Autoritate/Subdiviziune · Solicitant · Sumă / Sumă achitată ·
Metodă de plată · Confirmat de · Data emiterii / Termen de achitare / Data achitării · Statut notă (Emisă / Achitată /
Parțial achitată / Neachitată / Expirată / Anulată / Rambursată) · Statut tranzacție MPay.
Constraints: strict read-only (nicio generare / corectare / anulare); fără reconciliere financiară.

## Criterii de acceptanță
AC-01: Un utilizator fără drept de acces la registrul de note de plată nu vede compartimentul „Registru note de plată” în BackOffice; accesul direct prin API e blocat cu mesajul «Acces interzis».
AC-02: Un utilizator, altul decât Administratorul Central, vede exclusiv notele din perimetrul autorității și subdiviziunii proprii; Administratorul Central vede toate notele din GEAP — testabil cu conturi din perimetre diferite.
AC-03: Căutarea și filtrarea funcționează simultan pe toate criteriile listate (Nr. notă de plată, Nr. MPay, datele solicitantului, perioadă, statut notă, statut tranzacție, sumă, metodă de plată, autoritate, subdiviziune, tip de serviciu, utilizatorul care a confirmat nota), combinate.
AC-04: Sortarea se aplică pe orice coloană; ordinea aleasă se păstrează pe durata sesiunii și se aplică identic la export.
AC-05: Deschiderea unei note afișează tranzacția MPay corelată automat, cu statutul acesteia (Finalizată cu succes / Eșuată / În așteptare / Anulată) actualizat în timp real, distinct de statutul notei de plată (Emisă / Achitată / Parțial achitată / Neachitată / Expirată / Anulată / Rambursată).
AC-06: Exportul CSV/XLSX/PDF returnează exact rezultatele curente (căutare și filtre aplicate), cu ordinea de sortare păstrată.
AC-07: Registrul nu afișează nicio acțiune de generare, corectare sau anulare a notelor de plată — nicio interfață de scriere pe date.
AC-08: Fiecare accesare a registrului generează o înregistrare în jurnalul de audit, cu utilizatorul, perimetrul aplicat (autoritate/subdiviziune) și marcajul de timp.
AC-09: Ecranul funcționează pe mobil, tabletă și desktop, fără derulare orizontală.
