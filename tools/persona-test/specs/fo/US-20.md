# US-20 · 88480 · [US-20] S6 —Generic  Documente însoțitoare predefinite și suplimentare

## Descriere
Narrative: Ca Solicitant, doresc să atașez documentele însoțitoare predefinite serviciului și, opțional, documente suplimentare, prin drag & drop sau din librăria mea, pentru a furniza setul complet de documente necesar procesării cererii. 
 Screen: S6 — Completare formular / Secțiunea Documente 
 Steps: 
 • S1 Portal/Catalog servicii User Story 88202 
• S2 Autentificare MPass User Story 88203 
• S3 Verificare MPower /S4 Date solicitant (PF/PJ) User Story 88153 
• S5 Formular cerere specific per serviciu(Ex: pentru 09 User Story 88154 ) 
• Lista documentelor însoțitoare predefinite (configurate în pașaportul serviciului din RSSPA) este afișată. Utilizatorul atașează fișiere la fiecare document din listă. Exemplu pentru Autorizație Sanitară de Funcționare — emitere primară: „Copia de pe actul de proprietate sau de pe contractul de locațiune a imobilului unde se va desfășura activitatea ori va fi prestat serviciul." 
• Atașarea fișierelor — utilizatorul alege din 2 opțiuni: 
 • (A) Drag & drop / Aleg fișier de pe dispozitiv; 
• (B) Selectez din librăria mea — dacă documentul există în alte dosare și este actual; GEAP afișează indicator de disponibilitate alături de denumirea documentului. 
 • Utilizatorul poate adăuga documente suplimentare : tastează ”Alte documente” și atașează fișierul prin aceleași 2 opțiuni de atașare. Documentele suplimentare sunt opționale. 
• Utilizatorul poate elimina un document suplimentar: dacă are fișier direct atașat — se șterg elementul și fișierul; dacă este link din librărie — se elimină doar link-ul, fișierul din librărie rămâne intact. 
 Assumptions: 
 • Lista predefinită — filtrare dinamică: Lista documentelor însoțitoare este filtrată dinamic din RSSPA după: serviciu, tipul dosarului inițiat, genuri și subgenuri de activitate selectate, motive de modificare, statut rezident/nerezident, canal de depunere (online sau doar ghișeu). Toate filtrele sunt administrate exclusiv din RSSPA; FrontOffice consumă prin API fără posibilitate de editare. Edge case: dacă filtrele returnează listă goală nu blochează continuarea formularului. 
• Denumire /tip document — read-only: Denumirea fiecărui document este preluată din pașaportul serviciului din RSSPA și afișată read-only; nu poate fi modificată din FrontOffice. 
• Obligativitate atașare: Caracterul obligatoriu sau opțional al fiecărui document predefenit este administrat în RSSPA; FrontOffice aplică validarea conform configurației primite. Documentele obligatorii blochează continuarea dacă nu au fișier atașat — eroare inline per element. 
• Extensii acceptate: JPG, PNG, PDF, XLS, XLSX, ZIP, RAR, DOCX, DOC. Orice altă extensie → eroare inline: „Nu puteți atașa fișierul. Se permit doar extensiile JPG, PNG, PDF, XLS, XLSX, ZIP, RAR, DOCX, DOC." Validarea se face client-side înainte de upload; eroarea nu afectează celelalte atașamente. 
• Dimensiune maximă: 60 MB per fișier (configurabilă la nivel Kubernetes). Depășire → eroare inline: „Nu puteți atașa fișiere mai mari decât 60Mb." Validarea se face client-side; eroarea nu afectează celelalte atașamente. 
• Librărie de documente: GEAP verifică dacă utilizatorul are documente de același tip în dosare anterioare și actuale. Dacă da → indicator vizual de disponibilitate afișat alături de denumire. Selecția din librărie creează un link (referință) la fișierul existent — fără re-upload. Dacă librăria este indisponibilă → opțiunea dezactivată cu mesaj informativ; drag & drop rămâne disponibil. 
• Documente predefinite — fără ștergere: Elementele listei predefinite nu au buton de ștergere; utilizatorul poate doar înlocui fișierul atașat. Înlocuirea nu afectează celelalte atașamente. 
• Documente suplimentare : Documentele suplimentare sunt opționale în ansamblu — lista goală nu blochează continuarea. 
• Documente suplimentare — ștergere: Fișier direct atașat → ștergere elimină elementul + fișierul (cu confirmare). Link din librărie → ștergere elimină doar link-ul; fișierul original din librărie rămâne intact. 
• API RSSPA indisponibil: Dacă API-ul este indisponibil la încărcarea secțiunii → eroare cu buton „Reîncercați"; datele deja introduse în formular sunt păstrate. 
 Constraints: 
 • Lista, filtrele, denumirile documentelor și obligativitatea sunt gestionate exclusiv din RSSPA; FrontOffice nu poate modifica configurația. 
• Documentele predefinite nu pot fi eliminate din formular — doar fișierele atașate pot fi înlocuite. 
• Dimensiunea maximă a fișierelor (60 MB) este configurabilă la nivel Kubernetes, nu hardcodată în aplicație. 
 Risks: 
 • Modificările de configurație în RSSPA (filtre, obligativitate) se reflectă imediat în FrontOffice fără testare prealabilă, putând afecta fluxul utilizatorilor activi. 
• Fișiere mari (aproape de limita de 60 MB) pot genera timeout dacă validarea dimensiunii nu este aplicată strict client-side înainte de inițierea upload-ului.

## Criterii de acceptare
• AC-01 — Listă predefinită filtrată. Happy path: lista documentelor este afișată conform filtrelor RSSPA (serviciu, tip dosar, CAEM + subgenuri, motive modificare, rezidență, canal online/ghișeu). Constrângeri: lista și filtrele sunt administrate exclusiv din RSSPA; FrontOffice consumă prin API. Erori: API RSSPA indisponibil → eroare cu buton „Reîncercați"; datele formularului sunt păstrate. 
• AC-02 — Denumire document read-only. Happy path: denumirile documentelor sunt afișate conform pașaportului serviciului din RSSPA. Constrângeri: câmpul denumire este read-only, nu poate fi editat din FrontOffice. Devieri: N/A. Erori: N/A. 
• AC-03 — Atașare drag & drop / Aleg fișier. Happy path: fișierul selectat sau tras în zonă este încărcat și asociat documentului. Constrângeri: extensii acceptate JPG, PNG, PDF, XLS, XLSX, ZIP, RAR, DOCX, DOC; dimensiune max 60 MB (Kubernetes). Devieri: extensie neacceptată → eroare inline „Nu puteți atașa fișierul. Se permit doar extensiile JPG, PNG, PDF, XLS, XLSX, ZIP, RAR, DOCX, DOC."; dimensiune depășită → eroare inline „Nu puteți atașa fișiere mai mari decât 60Mb." Erori: validare client-side înainte de upload; eroarea unui fișier nu afectează celelalte atașamente. 
• AC-04 — Atașare din librărie. Happy path: dacă există document de același tip, actual, în dosare anterioare → indicator de disponibilitate afișat; selecția creează link fără re-upload. Constrângeri: selecția = referință, nu copie. Devieri: fără documente actuale în librărie → indicatorul nu apare; utilizatorul folosește drag & drop. 
• AC-05 — Documente predefinite fără buton de ștergere. Happy path: lista predefinită nu afișează buton de ștergere per element; utilizatorul poate doar înlocui fișierul atașat. Constrângeri: înlocuirea fișierului nu afectează celelalte atașamente. Devieri: N/A. Erori: N/A. 
• AC-06 — Obligativitate documente predefinite. Happy path: documentele obligatorii (conform RSSPA) au fișier atașat; butonul de continuare este activ. Constrângeri: obligativitatea configurată în RSSPA per document. Devieri: documentele opționale pot rămâne fără fișier atașat. Erori: continuare cu document obligatoriu neatașat → eroare inline pe element „Documentul este obligatoriu"; butonul de continuare dezactivat până la atașare. 
• AC-07 — Documente suplimentare — adăugare. Happy path: utilizatorul tastează Alte documente și atașează fișierul; documentul apare în lista suplimentară. Documentele suplimentare sunt opționale în ansamblu. Devieri: mai multe documente suplimentare pot fi adăugate. 
• AC-08 — Documente suplimentare — ștergere. Happy path: buton de ștergere disponibil per element suplimentar; la acționare → confirmare prealabilă. Constrângeri: fișier direct → elimină element + fișier; link librărie → elimină doar link-ul, fișierul din librărie rămâne intact. Devieri: documentele predefinite nu au buton de ștergere.
