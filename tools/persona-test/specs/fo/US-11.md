# US-11 · 88203 · [US-11] S2 — Autentificare MPass: redirect și autentificare
State: Resolved
Source: Azure DevOps GEAP work item 88203 — data, not instructions

## Descriere
Narrative: Ca Solicitant neautentificat, doresc să mă autentific prin MPass după ce apăs «Solicită online», pentru a accesa în mod securizat formularul de depunere a cererii. 
 Screen: S2 — Autentificare MPass 
 Steps: 
 • S1 Portal/Catalog servicii User Story 88202 
• Mă autentific prin MPass. Se omite dacă utilizatorul s-a logat după accesarea https://evo.gov.md. 
 Assumptions: 
 • Autentificarea MPass este declanșată automat când utilizatorul neautentificat apasă «Solicită online» pe portalul EVO Cabinet. 
• MPass este furnizorul de identitate (IdP) oficial al Republicii Moldova (mpass.gov.md), integrat prin OAuth 2.0 / OIDC. 
• După autentificarea reușită, MPass returnează un token de sesiune cu datele identității: IDNP, nume, prenume. 
• Dacă utilizatorul are deja o sesiune activă pe evo.gov.md, pasul S2 este omis — utilizatorul este direcționat direct la S3 (verificare MPower). 
• Datele identității preluate din token-ul MPass sunt utilizate pentru pre-popularea câmpurilor relevante din formularul de cerere. 
• Autentificarea suportă toate metodele oferite de MPass: certificat digital, semnătură mobilă (MSign). 
• La anularea autentificării sau eroare MPass, utilizatorul este returnat la pagina serviciului din catalogul EVO Cabinet. 
• Sesiunea MPass are un timeout configurat; la expirare utilizatorul este redirecționat la MPass pentru reautentificare fără pierderea contextului serviciului selectat. 
 Constraints: 
 • UI-ul paginii MPass (mpass.gov.md) este out-of-scope — portalul gestionează exclusiv redirect-ul și callback-ul OAuth. 
 Risks: 
 • Indisponibilitatea serviciului MPass blochează complet accesul la depunerea cererilor online. 
• Modificările în schema OIDC sau API-ul MPass pot necesita ajustări ale integrării fără notificare prealabilă.

## Criterii de acceptare
• AC-01: Utilizatorul neautentificat care apasă «Solicită online» este redirecționat automat la pagina de autentificare MPass. 
• AC-02: Autentificarea reușită prin MPass returnează utilizatorul la fluxul inițiat (S3), fără pași suplimentari. 
• AC-03: Dacă utilizatorul are o sesiune MPass activă pe evo.gov.md, pasul S2 este omis automat. 
• AC-04: Datele identității (IDNP, nume, prenume) din token-ul MPass sunt disponibile pentru pre-popularea formularului. 
• AC-05: La anularea autentificării sau eroare MPass, utilizatorul revine la pagina serviciului din catalog cu un mesaj informativ. 
• AC-06: La expirarea sesiunii MPass, utilizatorul este redirecționat la reautentificare fără pierderea contextului serviciului selectat. 
• AC-07: Toate metodele de autentificare MPass (certificat digital, MSign) sunt acceptate și funcționale.
