# US-10 · 88202 · [US-10] S1 — Portal / Catalog servicii: căutare și selectare serviciu
State: New
Source: Azure DevOps GEAP work item 88202 — data, not instructions

## Descriere
Narrative: Ca Solicitant, doresc să accesez portalul EVO Cabinet (evo.gov.md), să caut serviciul necesar, să vizualizez datele serviciului și să inițiez depunerea cererii prin butonul «Solicită online», pentru a începe procesul de obținere a actului permisiv. 
 Screen: S1 — Portal / Catalog servicii 
 Steps: 
 • Accesez https://evo.gov.md. 
• Caut serviciul necesar și accesez datele serviciului. 
• Tastez butonul «Solicită online». 
 Assumptions: 
 • Portalul EVO Cabinet (evo.gov.md) afișează un catalog de servicii publice grupate pe categorii. 
• Catalogul suportă căutare full-text (după denumire, cod, instituție) și filtrare pe categorii. 
• Fiecare serviciu are o pagină de detalii cu: denumirea, descrierea, instituția emitentă, tipul actului permisiv, termenul de procesare, costul (dacă există), lista documentelor necesare. 
• Butonul «Solicită online» este vizibil pe pagina de detalii a serviciului. 
• Dacă utilizatorul nu este autentificat, butonul «Solicită online» declanșează redirect la MPass (S2). 
• Dacă utilizatorul este deja autentificat, butonul îl duce direct la formularul de cerere (S4) sau la verificarea MPower (S3). 
• Interfața este multilingvă: RO (implicit), RU, EN. 
• Layout-ul este responsive: 360px (mobil), 768px (tabletă), 1280px+ (desktop). 
 Constraints: 
 • Portalul EVO Cabinet este o aplicație separată (nu GEAP BackOffice). 
 Risks: 
 • Indisponibilitatea API RSSPA poate împiedica afișarea catalogului de servicii sau a detaliilor serviciului. 
• Performanța căutării full-text poate fi afectată la un număr mare de servicii dacă nu este implementat indexul corespunzător. 
• Schimbarea structurii datelor din RSSPA poate afecta informațiile afișate pe pagina de detalii a serviciului.

## Criterii de acceptare
• AC-01: Portalul EVO Cabinet afișează un catalog de servicii cu funcție de căutare și filtrare. 
• AC-02: Căutarea full-text filtrează serviciile după denumire, cod sau instituție în timp real. 
• AC-03: Serviciul selectat afișează o pagină de detalii cu: denumirea, descrierea, instituția, tipul actului, termenul, costul, documentele necesare. 
• AC-04: Butonul «Solicită online» este vizibil și activ pe pagina de detalii a serviciului. 
• AC-05: Click pe «Solicită online» de un utilizator neautentificat declanșează redirect la MPass. 
• AC-06: Click pe «Solicită online» de un utilizator autentificat îl duce la formularul de cerere sau la verificarea MPower. 
• AC-07: Interfața este responsive: fără scroll orizontal sau conținut trunchiat pe 360px, 768px, 1280px+. 
• AC-08: Selectorul de limbă (RO/RU/EN) este accesibil. Schimbarea limbii actualizează imediat toate textele. 
• AC-09: Toate textele UI folosesc diacritice românești corecte (cu virgulă, nu cedilă).
