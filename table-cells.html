Table cells

One composable cell family for every table in the product. Three ideas do the work: .cell is the horizontal row, .cell__body is the vertical text column, and the modifiers are orthogonal so they combine freely. Drop it into any <td> — it owns no table chrome.

In context

A realistic registry row. Hover a row for the trailing chevron, hover or tab to a copy button, and tab to the truncated permit name — the tooltip only appears when text is actually clipped.
